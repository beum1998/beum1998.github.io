# Viewer demo — Villa Savoye (synthetic log)

A static copy of the Augmented BIM Log web viewer (`FullyVisualization/`) with a **synthetic** log in `src/finalLogs/`.
The log was generated by a rule-based Revit emulator (`tools/synth/` in the `code_log` repository), not recorded in Revit,
and the model is an approximation of Le Corbusier's Villa Savoye built from published dimensions (4.75 m grid, 19 × 21.5 × 9.4 m).
Pins you add here are kept in your browser only (there is no add-in server behind this page).
